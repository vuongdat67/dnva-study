# A3 – Sensitive Data Exposure

## Scenario

- API trả dữ liệu nhạy cảm: `/admin/usersapi`

## Mô tả lỗ hổng

API trả toàn bộ record từ bảng `Users` bao gồm `password` (hash bcrypt), `role`, và các trường nội bộ. Không có kiểm soát field output.

## Khai thác

**Vị trí code (v1):** `core/appHandler.js` – hàm `listUsersAPI`

```js
db.User.findAll().then(users => res.json(users))
```

**Truy cập:** `GET /admin/usersapi` (chỉ cần login, không cần role admin)

**Response trả về:**
```json
[
  {
    "id": 1,
    "name": "Admin",
    "login": "admin",
    "email": "admin@example.com",
    "password": "$2b$10$...",
    "role": "admin",
    "createdAt": "...",
    "updatedAt": "..."
  }
]
```

## Tác động (Impact)

- Leak password hash → brute-force offline
- Lộ email, role của toàn bộ người dùng

## Fix (v2)

```js
db.User.findAll({ attributes: ['id', 'name', 'email'] })
  .then(users => res.json(users))
```

Chỉ trả về field cần thiết, bỏ `password`, `login`, `role`.

## Kết quả sau fix

- API chỉ trả `id`, `name`, `email`
- Password hash không còn trong response
