# A10 – Insufficient Logging & Monitoring

## Scenario

- Ứng dụng không log các sự kiện bảo mật quan trọng
- Không có alerting khi có dấu hiệu tấn công

## Mô tả lỗ hổng

DVNA dùng `morgan('tiny')` chỉ log HTTP request cơ bản. Không có log cho:
- Đăng nhập thất bại nhiều lần (brute-force)
- Truy cập trái phép vào admin endpoint
- SQL query bất thường
- Lỗi authentication/authorization

## Biểu hiện trong code (v1)

**`server.js`:**
```js
app.use(morgan('tiny'))
// Chỉ log: GET /login 200 - 5ms
// Không log: ai login, có thành công không, IP là gì
```

**Không có log khi:**
- Login sai password 100 lần liên tiếp → không ai biết
- User thường GET `/admin/usersapi` → không cảnh báo
- SQLi payload trong request body → không lưu lại

## Tác động (Impact)

- Attacker brute-force mật khẩu mà không bị phát hiện
- Sau khi bị tấn công không thể điều tra forensics (không có log)
- Không đáp ứng yêu cầu compliance (GDPR, PCI DSS yêu cầu audit log)

## Fix (v2)

**Thêm security logging với winston:**

```js
const winston = require('winston')
const logger = winston.createLogger({
  level: 'info',
  format: winston.format.json(),
  transports: [new winston.transports.File({ filename: 'security.log' })]
})

// Log login attempt
module.exports.loginAttempt = function(username, success, ip) {
  logger.info({
    event: success ? 'LOGIN_SUCCESS' : 'LOGIN_FAILED',
    username,
    ip,
    timestamp: new Date().toISOString()
  })
}

// Log unauthorized access
module.exports.accessDenied = function(req) {
  logger.warn({
    event: 'ACCESS_DENIED',
    path: req.path,
    user: req.user?.login,
    ip: req.ip
  })
}
```

**Thêm rate limiting để phát hiện brute-force:**
```js
const rateLimit = require('express-rate-limit')
const loginLimiter = rateLimit({
  windowMs: 15 * 60 * 1000,  // 15 phút
  max: 10,                    // tối đa 10 lần
  message: 'Too many login attempts'
})
app.use('/login', loginLimiter)
```

## Kết quả sau fix

- Mọi login attempt được ghi vào `security.log` kèm IP, username, kết quả
- Brute-force bị chặn sau 10 lần trong 15 phút
- Admin access được audit đầy đủ
