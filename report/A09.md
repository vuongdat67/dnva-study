# A9 – Using Components with Known Vulnerabilities

## Scenario

- Các dependency trong `package.json` dùng phiên bản cũ, có CVE đã công bố

## Mô tả lỗ hổng

Ứng dụng dùng nhiều package cũ với lỗ hổng đã biết. Attacker có thể khai thác trực tiếp từ CVE database mà không cần phân tích code.

## Các package có lỗ hổng nghiêm trọng (v1)

| Package | Version cũ | Lỗ hổng | Mức độ |
|---------|-----------|---------|--------|
| `bcrypt` | `1.0.3` | NODE_MODULE_VERSION mismatch, không compile được | Build fail |
| `libxmljs` | `0.19.1` | XXE, memory corruption, không hỗ trợ Node 12+ | Critical |
| `node-serialize` | `0.0.4` | CVE-2017-5941 — RCE qua IIFE deserialization | Critical |
| `mathjs` | `3.10.1` | Arbitrary code execution qua `eval()` | High |
| `sequelize` | `4.x` | SQL injection nếu dùng raw query (không dùng parameterized) | High |
| `express-fileupload` | `0.4.0` | Prototype pollution (CVE-2020-7699) | High |
| `csurf` | `1.9.0` | Archived, không còn bảo trì | Medium |

**Kiểm tra bằng npm audit:**
```bash
npm audit
# Output: 17 vulnerabilities (2 low, 1 moderate, 7 high, 7 critical)
```

## Tác động (Impact)

- Attacker tra CVE → có sẵn PoC exploit → tấn công không cần phân tích code
- `node-serialize` → RCE (xem A8)
- `express-fileupload` → prototype pollution → bypass logic check

## Fix (v2)

Nâng version các package có lỗ hổng:

```diff
- "bcrypt": "^1.0.3"
+ "bcrypt": "^5.1.1"

- "libxmljs": "^0.19.1"
+ "libxmljs2": "^0.31.0"

- "node-serialize": "0.0.4"   → loại bỏ, dùng JSON.parse

- "mathjs": "3.10.1"
+ "mathjs": "^11.0.0"

- "express-fileupload": "^0.4.0"
+ "express-fileupload": "^1.4.0"
```

**Quy trình kiểm tra định kỳ:**
```bash
npm audit              # kiểm tra lỗ hổng
npm audit fix          # tự fix nếu không breaking change
npm audit fix --force  # fix kể cả breaking change (cần test lại)
```

**CI integration:** Trivy scan image trong GitHub Actions tự động báo CRITICAL/HIGH sau mỗi build.
